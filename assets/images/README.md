# Taruh gambar PNG kata kunci di sini

* Format: PNG, latar transparan, persegi (disarankan 1000 x 1000 px atau lebih), gaya kartun garis tebal yang sama untuk semua.
* Nama file = kata Inggris huruf kecil, spasi/tanda hubung menjadi garis bawah. Huruf besar/kecil nama file tidak dipermasalahkan.
  Boleh juga folder `assets/Images/`. Atau tulis nama lain di kolom `Image` (sheet Letters), tanpa `.png`.
* Belum ada file -> halaman memakai kotak teks biasa (demo). Daftar lengkap: jalankan dengan `--export-prompts` -> `image_prompts.csv`.

Nama file untuk contoh bawaan (26 huruf):
apple.png  ball.png  cat.png  dog.png  egg.png  fish.png  goat.png  hat.png  ice_cream.png  juice.png  kite.png  lion.png  moon.png
nest.png  orange.png  pen.png  queen.png  rabbit.png  sun.png  tree.png  umbrella.png  violin.png  whale.png  xylophone.png  yo_yo.png  zebra.png
